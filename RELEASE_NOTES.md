The home screen is reorganized: **Games** holds every way to get games onto the Deck (Arcadia for retro games, Heroic, Lutris, itch, Prism Launcher, Nexus Launcher for Xbox PC games, and the Windows stores), and **Tools** holds what helps games run (GE-Proton, ProtonUp-Qt, Protontricks, Bottles), Deck tools (Decky Loader, Flatseal, Ludusavi) and Discord, each under headings. Everything Deckhand installs can now be uninstalled from Deckhand: removing a store or streaming service can uninstall its app or browser too (unless something else still uses it), a browser nothing uses any more is listed under Installed, GE-Proton has Uninstall, and ☰ Menu → Uninstall Deckhand removes Deckhand itself. A shortcut left in Steam by an uninstall while Steam was open is removed by itself the next time Steam is closed. Deckhand opens about four times faster: it no longer unpacks itself on every start. It tells you about updates to itself and its add-ons with a notification, in Game Mode too. Fixes from testing on a Steam Deck: GE-Proton installs the right build for the Deck's processor (it took the ARM one), apps opened from Deckhand no longer quit at once when it was started from a code editor, a Windows store waits while Steam installs the runtime it needs, Free up space finds folders Steam leaves behind after an uninstall, Games shows which Arcadia you have, and the home screen fits a scaled desktop. Apps installed from Flathub get what they need on a Deck as they install: Protontricks, Bottles and itch can now see games on an SD card.
